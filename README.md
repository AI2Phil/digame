## 🚀 **Getting Started**

### **Quick Start (5 Minutes)**
```bash
# 1. Clone the repository
git clone <repository-url>
cd digame

# 2. Set up environment (automated)
python scripts/setup_dev_env.py

# 3. Activate environment
source scripts/activate_digame.sh

# 4. Configure environment
export DIGAME_AUTH_SECRET_KEY="your-super-secret-key-at-least-32-characters-long"
export DIGAME_AUTH_DEFAULT_ADMIN_EMAIL="admin@yourdomain.com"

# 5. Initialize database
python scripts/deploy_migrations.py

# 6. Start the application
python -m uvicorn digame.app.main:app --reload
```

### **Access the Complete Platform**
- **API Documentation**: http://localhost:8000/docs (150+ documented endpoints)
- **Application Dashboard**: http://localhost:8000
- **Health Check**: http://localhost:8000/health
- **Admin Panel**: Complete enterprise management interface
- **Mobile App**: Full feature parity with web platform
- **Analytics Dashboard**: Real-time insights and performance metrics

### **Enterprise Docker Deployment**
```bash
# Production-ready deployment
docker-compose -f docker-compose.prod.yml up --build

# Enterprise scaling
docker-compose -f docker-compose.enterprise.yml up --scale api=3 --scale worker=5

# Access the application
open http://localhost:8000
```
