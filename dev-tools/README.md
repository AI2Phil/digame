# Development Tools and Analysis

This directory contains development tools, analysis files, and archived configurations that are not part of the main application but useful for development and maintenance.

## Files

### Analysis Files
- `circular_import_analysis.json` - Analysis of circular imports in the codebase (generated by development tools)
- `integration_analysis.json` - Analysis of integration opportunities between Digame and DigitalTwinPro components

### Requirements Archives
- `requirements-nested.txt` - Alternative requirements file with nested dependencies
- `requirements.txt.backup` - Backup of previous requirements configuration
- `temp_requirements.txt` - Temporary requirements file used during development

### Archived Files
- `digame-nested.gitignore.archive` - Previous version of gitignore file (archived, main .gitignore in root is comprehensive)

## Usage

These files are primarily for:
- Code analysis and debugging
- Development workflow optimization
- Historical reference
- Troubleshooting import issues
- Requirements management and dependency analysis
- Integration planning and analysis

## Note

Files in this directory are not part of the production deployment and are excluded from Docker builds.
